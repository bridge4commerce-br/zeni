# Status atual do Zeni

Este arquivo não é a fonte operacional de contexto do projeto. Consulte
[`docs/context/zeni-context-current.md`](context/zeni-context-current.md).

O Zeni V2 possui persistência local, funcionamento offline-first, autenticação
opcional e integração Supabase para sync e restauração. Família e Ajustes já
fazem parte do rollout visual V2; este status substitui as afirmações antigas
de dados mockados, ausência de persistência e ausência de Supabase.
